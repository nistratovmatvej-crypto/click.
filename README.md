# click

Минималистичная браузерная игра: одна кнопка, одно нажатие, короткий звук.

## Файлы
- `index.html` — игра.
- `404.html` — страница ошибки.
- `privacy.html` — политика конфиденциальности.
- `robots.txt` и `sitemap.xml` — индексация.
- `favicon.svg` — иконка сайта.
- `click-preview.svg` — векторное превью.
- `_headers` — HTTP-заголовки для Cloudflare Pages.

## Перед публикацией
Замени `YOUR-DOMAIN.com` в `index.html`, `robots.txt` и `sitemap.xml` на реальный домен. Если используется адрес Cloudflare Pages, укажи его.

Cookie-баннер и аналитика не добавлены: проект не использует cookies, формы, рекламу или сторонние трекеры. Формы и антиспам отсутствуют, поэтому валидация и защита от спама не требуются. Отдельные условия использования сейчас не нужны: нет аккаунтов, оплат и пользовательских публикаций.

Для Android APK позже можно обернуть этот же веб-проект в Android-приложение (например, через Capacitor или Trusted Web Activity). Текущая версия не содержит серверной части.
